**What.** KERNEL-V1-SPEC 3.2.

**How.** `abi::Handle(u64)`; `kcore::handle`: `SLOT_BITS = 24`, generation `u64` masked to 40 bits, retirement at 2^40; the slot vector grows on demand (push) and `MAX_HANDLES` becomes the job's object quota, with `abi::limits::MAX_HANDLES` removed (this takes up T8). Syscall layer: handle arguments are full registers; the rule "a 32-bit argument with high bits set is BAD_HANDLE" goes for handles (it stays for rights and masks). Handle arrays copied in and out are 8 bytes each (`handle_list`, `channel_write`, `channel_read`, `channel_call` argument record: restate `CHANNEL_CALL_ARGS_BYTES`). Userland in the same PR: `rt` (every wrapper, the startup message reader), `proto` (wire formats that carry handle values or handle counts: the startup message's role table; goldens regenerated by hand-derivation, not by blessing), `libc` (the fd table), every server and program in `init/`. `SYSCALLS.md` ABI section and `INVARIANTS.md` H2 rewritten.

**Acceptance, written first.** `kcore/tests/handle_model.rs` extended: slot numbers above 8191; a table of 100,000 live handles; the retirement test with the generation fast-forwarded to 2^40 - 2 (a test-only constructor). A suite test holds 20,000 handles in one process. Counter fast-forward (`ff=handlegen:<n>` once AB3 has the mechanism; until then the host test stands). The whole suite at 1, 2, 4 harts.

**Review.** Fable, soak. One PR; the system does not build half-converted.

Progress (2026-11-20): done in one PR. `abi::Handle(u64)`; `kcore::handle` with 24 slot bits, a 40-bit generation, retirement at 2^40, a table that grows on demand (`HandleTable::starting_at_generation` and `with_slot_cap` are test-only knobs); `abi::limits::MAX_HANDLES` removed (the table limit is `kcore::handle::MAX_SLOTS`, the job's quotas bound it in practice); `ksys`: no width rule on handle arguments (it stays for rights, masks and `txid`), handle lists 8 bytes each (`CHANNEL_CALL_ARGS_BYTES` stays 56: that record holds pointers and counts); `rt`, `libc` (the fd table, the static atomics), `svc`, `pathres` and every program in `init/` widened (compiler-guided, then by hand); SYSCALLS.md and INVARIANTS H2 rewritten. Tests: `kcore/tests/handle_model.rs` (100,000 live handles, slots above 8191, the retirement test with the generation at 2^40 - 2, the 40-bit generation in the high bits), the guest test `a_process_holds_twenty_thousand_handles`, `ksys`'s `thread_create_with_a_full_handle_table` (the guest test could not fill a 2^24-slot table: it is a host test now). Run by hand: the kernel-only shard at four harts (241 tests pass), host tests of `kcore`, `ksys` and the crates around them, both lint targets. Not run: one and two harts, the C and Lua transcripts, BusyBox (the epic gate).
