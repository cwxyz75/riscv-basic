## Shortcut

**Files in the C library are limited (S7c-3a).** There is no ambient `/tmp`: absolute paths resolve against the `/` namespace entry (the shell gives only a read-only one to trusted programs), `tmpfile`/`tmpnam` make scratch files in the working directory, and a shell-started program has no writable place at all (T33); the fd table holds 256 entries and the `FILE` table 64; one global lock covers every fd operation including blocking file-protocol calls (a slow server stalls all of a program's threads' file I/O); `ungetc` keeps one character; `struct stat` is `{size, mode}`; the stream functions are not thread-safe per stream beyond that lock.

## Why it was acceptable

Enough for Lua's `io` library on a granted directory.

## Proper fix, and when

A writable per-program scratch directory from the launcher; per-fd locks; `sscanf`/`fscanf` if a program needs them.
