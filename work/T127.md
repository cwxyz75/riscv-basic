## Shortcut

**`ish` interactive layer (SH5) shortcuts** (2026-11-17):

- (1) the non-interactive mode (`repl::run_batch`, chosen when the shell has no console server) is tested on the host (golden 56) but not in QEMU: a test needs a stack without `consoled`
- (2) the history lives in memory for the session only (no history file)
- (3) a lone Escape key waits for the next byte (no timeout), Alt-keys are ignored, characters are assumed one column wide, and the editor never asks the terminal its size (a line longer than the screen wraps and the cursor arithmetic is then wrong)
- (4) completion is of names in the shell's table (directory listings), commands (builtins, functions, `/bin`) and variables; it is not aware of attributes; a quoted word is not completed
- (5) a command continues on the next line only for an unfinished block, bracket, pipe or list: an unterminated quote is an error at once (the S4e test expects that); a multi-line command is not entered in the history
- (6) a loop of shell code asks the host about an interrupt every 4096 statements or iterations
- (7) between prompts the terminal is in raw mode (signals on, no echo) and programs run with it cooked; a Ctrl-C typed in the instant between Enter and the program starting is caught when the job is registered. Fix: (1) with the next test that needs a consoled-free session. (The scheduling question that item (6) once held is resolved: R29.)

## Note (2026-11-18, T151)

Checked: (1) is resolved: the UV5 sessions test (`sessions_test` in init.rs) runs a shell with no console server in QEMU, reading its script from the terminal socket. The other items stand.
