## Shortcut

**No thread cancellation in the libraries** (design review D9). `thread_interrupt` is built (2026-11-17): a blocked or about-to-block wait returns `INTERRUPTED`; it does not stop a thread that is running user code. The C library has no `pthread_cancel` (T52) and does not use the call (a signal-watcher thread for `alarm` in a CPU loop, T137), and the service runtime has no request cancellation.

## Why it was acceptable

The kernel half is done and tested (nine suite tests); the library half is not built.

## Proper fix, and when

`pthread_cancel` in the C library (deferred or asynchronous per POSIX), and cancellation in the service runtime's request handling. Plan: resolved by SCHED-SMP-SPEC task 26.
