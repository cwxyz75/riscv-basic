**What.** INVARIANTS K1 and its successors are `debug_assert!`, so the release SMP run checks none of them, and the debug run has different timing.

**How.** A Cargo profile `release-checked` for the kernel (`inherits = "release"`, `debug-assertions = true`, `overflow-checks = true`). Target `os-boot-test-checked`: the whole suite at `-smp 4` and the `k` shard at `-smp 1`, `2`, `8` on that kernel. Overnight.

**Acceptance.** A planted K1 violation (state touched without its lock on a rare path) panics in this build and passes silently in plain release, shown once by hand.

**Review.** Default.
