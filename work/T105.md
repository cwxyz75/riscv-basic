## Shortcut

**Wall-clock shortcuts** (`FS-SPEC.md` section 7; built in step C1, see T116): the only RTC is QEMU `virt`'s (a goldfish RTC, address and register behaviour now verified against the device tree and a boot); no `Set`, no network time (NTP over S9 later); with no RTC the clock is `Unset` and counts from the epoch, so file times are meaningless there; no leap-second or timezone handling (UTC nanoseconds only); the slew model assumes the monotonic clock does not stop.

## Why it was acceptable

Enough for file timestamps and logs on QEMU.

## Proper fix, and when

Verify against the device tree; add `Set` and an NTP client; a persisted last-known time for boards without an RTC.
