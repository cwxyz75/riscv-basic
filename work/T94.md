## Shortcut

**The filesystem has no hard links** (F3): one directory entry per node, a parent id in every inode.

## Why it was acceptable

Buys scoped queries, simple quota charging and a simple checker; the POSIX layer answers `link` with not supported.

## Proper fix, and when

Reconsider if ported software needs `link` (S11), or if a union or packaging story wants shared files; the cost is link counts, orphan rules with several names and an unambiguous quota owner. Decide before the format is frozen.
