**What.** The audit's `weak` rows (`kt14-unsafe-audit.tsv`, verdict `weak`; the one-line note says what the comment should say): e.g. `kmem.rs` `jobs()`/`get()`/`get_as()`/`mem()`/`frames()` (the `&'static mut` is sound only while the guard beside it lives, and the type does not enforce that; the comment on `get()` says things that are no longer true), `kmem.rs` `snapshot_kernel_half` ("interrupts off or a single thread" is false at that call), `kstack.rs` `Deref` (aliasing while the thread runs on the stack), `thread.rs` SCHED reads ("one hart" is false: the gate is `SCHEDULER_READY`), `percpu.rs` `HeldCell`, `fp.rs` (interrupts-off unstated; `VecHartUnit::load` has no length check; `light_save` comments), `aia.rs`, `sbi.rs` (`a0-a2` vs a0-a4, "changes no kernel state"), `trap.rs:496` (clears FS and VS, the comment says FS only), the `aarch64` stubs.
**Why acceptable.** The conditions hold on every path the reviewers traced; the comments are what is wrong.
**Proper fix.** Rewrite each comment to state the condition and what makes it true; the hash then changes and the row is re-audited (the docs check enforces it). Do it in one pass.
