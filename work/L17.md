## Note (2026-11-18, plan 4: the v1 kernel)

Amended by KERNEL-V1-SPEC 4.5 so that pager waits (MM9) need no redesign: the fault path takes `AS` to find the region and a VMO reference and to read the region's generation, **releases `AS`**, asks the family for the page, re-takes `AS`, and maps only if the generation is unchanged (otherwise it retries from the top). `AS` is never held across the family's slow path. Regions get the generation counter here. The loom acceptance gains: a fault against an unmap of the same region between the two `AS` sections (the fault must not map into the hole). Includes the single-page flush of MM1 in its final form (by ASID). Plan 4 (`WORK-PLAN.md`) orders this item and carries the owner's go-ahead for it; the sentence above about waiting for a go-ahead and the ordering gate no longer applies (the order is the plan's, changed only on the evidence of the lock profile, recorded as a decision).
