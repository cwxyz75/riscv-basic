title: Two files are below 80 % line coverage on the host (KT11): abi/src/lib.rs and ksys/src/vmo.rs
refs: [KT11, TS3]
---

KT11's first coverage run (2026-11-20) found two files under 80 %. `abi/src/lib.rs` (55.7 %): the `Rights` helpers `contains`, `union`, `is_subset_of` and `is_valid`, `Status::code` and `Status::from_code`, and `layout::in_device_window`, which no test inside `abi` calls (other crates call them, and the OS tests exercise them in QEMU, but a host test in `abi` should pin each: a round trip of every status code, the subset and union laws, the window's edges). `ksys/src/vmo.rs` (59.1 %): the success paths of `vmo_create_physical`, `vmo_create_dma` and `vmo_phys_addr` (the fake machine in `ksys/tests/common` has no resource handle or DMA window yet). Why acceptable: the helpers are one-line and used everywhere, so a defect shows at once; the VMO paths are exercised in QEMU by `device_caps_need_the_resource`. Proper fix: add the tests above, then re-run `make os-coverage`; both files should pass 90 %.
