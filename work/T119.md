## Shortcut

**User-view decisions that wait for UV5** (recorded 2026-11-17): `/etc/passwd` and `/etc/group` will be static one-entry files from the boot image in UV2; there is no authentication, no profile format and no multi-user sharing until the session manager (UV5); the `/etc/trusted` list stays the way a program is widened until profiles and the manifest replace it; `/pkg` unions wait for the union server (S10).

## Why it was acceptable

Enough for a single-owner development system.

## Proper fix, and when

Authentication, enrolment and recovery are now designed (`USER-VIEW-SPEC.md` 10.1, 2026-11-16): `authd` separate from the session manager, a memory-hard password hash, and the profile format still to settle at UV5 (Q7). **Shortcuts the first build keeps:** recovery is physical-console reset only (configurable recovery, a second credential and a recovery key wait for Q13), and home volumes are unencrypted (Q14), so the password gate is the whole defence. Build in UV5 and UV5a.
