## Shortcut

**CI is still serial inside each job** (the Rust build is cached since the workflow-speed PR, and docs-only changes skip the boot jobs; the kernel checks now run as parallel jobs, about 2 minutes each, and the whole `make check` takes about 3 minutes locally warm; the smoke job takes about 7 minutes in CI against its 10-minute budget, since S9 grew the suite; the harness has a 240 s per-kernel timeout).

## Why it was acceptable

Fast enough now.

## Proper fix, and when

Cache the QEMU install; parallelise further only if it gets slow again (the smoke job is now the longest; watch it against its budget: the fail-demo already had to move out of it).
