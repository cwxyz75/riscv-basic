**What.** Found by IOMMU12's review (2026-11-27); the specs are off limits to agents, so this waits for the owner.

1. **IOMMU-SPEC 15.1 has no entry for `iommu-testdev`.** The boot harness and CI put QEMU's `iommu-testdev` at slot 8 so that
   the hostile-driver matrix has a device that writes where it is told (`scripts/os_boot_test.py` PCI_DEVICES,
   `.github/workflows/qemu.yml`). Its read-back (BAR0 registers 0x1c and 0x20) compares memory at a *physical* address, outside
   the IOMMU. Its BAR lies in the admitted PCI memory window, and the kernel cannot cut it (BARs are assigned at run time). So a
   holder of the root resource that maps the BAR can probe physical memory: one bit per 8 bytes, the kernel's included, and
   whether a frame is the one it wrote. A release kernel is affected too.
   - No driver can do this: `devmgr` never claims the device (it has no MSI-X) and hands out no BAR for it.
   - INVARIANTS D2 names it as an exception since IOMMU12. The spec should list it beside L1, as an L7: "a test-only device of
     the test machine; not on any machine the system ships for". It could also require the harness to leave it off the boots
     that do not run the matrix, such as the release smoke test, which already has no such device.
2. **Stale text about the retired calls.** NET-DESIGN.md (around lines 29 and 628) still says the DMA right gates
   `vmo_phys_addr`. S6-SPEC.md (around lines 56 to 58, 146, and 193 to 194) describes `vmo_create_dma` and `vmo_phys_addr` as
   calls. S6-SPEC has an amendment at around line 199. Since IOMMU12 both are library stubs answering NOT_SUPPORTED, and their
   numbers are retired.

**Why acceptable.** It is development-only. The device is on the test machine only, and only the root-resource holder (the
suite, `devmgr`) can map it. The reference documents (SYSCALLS, INVARIANTS) are correct.

**Risk.** A reader of the spec believes the test machine has no path to physical addresses from user mode.

**Proper fix, and when.** The owner amends IOMMU-SPEC 15.1 (L7) and NET-DESIGN and S6-SPEC with dated amendments. Do it with
the drivers epic's merge into `main`.
