## Shortcut

**`ish` (SH1 to SH3) shortcuts** (2026-11-17):

- (1) the syntax hooks (`%pipe`, `%and`, ...) of SHELL-SPEC section 5 are not built, so there is nothing to redefine and SHI1 holds trivially
- (2) a shell callee can only start or end a pipeline, and a producer's output is buffered up to the capture cap; stderr drained to memory is read after stdout when a consumer stage reads stdout (a program filling its stderr pipe while the shell reads stdout could deadlock on a real host)
- (3) call depth is capped at 48 and parser nesting at 64, sized for a 2 MiB stack in a debug build: SH4 must size the OS program stack or lower them
- (4) decimal division needs operands that fit i128 after scaling by 10^18 (about 20 digits), otherwise it is an overflow error
- (5) **resolved by grammar v2 (SH2b, #196)**: templates, `spawn` and the job builtins exist (shell-level job control stays Q7)
- (6) **resolved**: the `es` differential is dropped and the independent oracles are Python and `bash` (`ish/tests/oracles.rs`, T129)
- (7) **resolved**: the grammar was reviewed by the owner and is SHELL-SPEC 5.2
- (8) the data crate's numbers stop at 38 digits (so `123e65` from JSON is refused). Fix: each when a real script needs it; (2) and (3) in SH4.
