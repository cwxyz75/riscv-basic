## Shortcut

**kilo (a first port that needs the terminal), 2026-11-17**: `kilo` (antirez's editor, 1300 lines, fetched and built unmodified, `init/src/bin/kilo.rs`) runs: raw mode, the window size, a read with a 100 ms timeout. The shell test types two letters, saves and quits under `hush` and `cat` shows the file. Not done: **`SIGWINCH`** (kilo installs a handler; nothing sends it: the console server's resize event is not mapped to the signal, so a window that changes size is not noticed), no terminal other than the serial console, the screen is redrawn whole each key (slow on a serial line), no UTF-8 width tables. The terminal flag now follows a duplicate (`Entry::Stream` carries it): a program a shell script starts sees a terminal where its starter had one.

## Why it was acceptable

A real interactive program on the terminal support, with no change to its source.

## Proper fix, and when

`SIGWINCH` from `Event::Resize`; a second port (`gzip`, `gnutar`, `sqlite`).
