## Shortcut

**The C library is a first cut (S7c-2).** (`FILE`, files and the fd table arrived with S7c-3a.) `errno` is one global per process (per-thread storage comes with pthreads); `qsort` is a heapsort (unstable, fine for C, slower than introsort); `malloc` rides the runtime's first-fit heap (about 15 MiB per program, T26) (small blocks now come from size-class free lists, S7d: the first-fit walk was quadratic for Lua's pattern, measured); `rand` is our own LCG (not glibc's sequence); the C transcript compares only what the C standard defines (no `strerror` text, no `%p`, no last-digit libm). Building the boot image now needs a RISC-V-capable clang (or `ctest` is a stub and its test fails): CI installs `clang llvm`, locally `brew install llvm` or `CC_RISCV`.

## Why it was acceptable

The slice's purpose was the ABI, the asm stubs and the C build path.

## Proper fix, and when

S7c-3 (FILE, fds, time, pthreads); measure malloc under Lua.
