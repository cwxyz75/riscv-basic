## Shortcut

**UV2 leftovers**:

- (1) the skeleton root is built by `memfsd` at start, not by a launcher per kind of program, and `/home` is still the boot-image fixtures (the spec's doofs home comes with profiles, UV5)
- (2) `ReadDir` still shows a symlink as a file (T109 (2)), so `ls /usr` lists `bin`, `include`, ... without a slash
- (3) `devd` has `null`, `zero` and (with a random service) `urandom` only: no `tty`, `fd/N` or `console`, and `rngd` is not started in a user session so `urandom` is absent there
- (4) the private `/tmp` of a job is a directory in the shared writable `/tmp` with no byte quota of its own (the server's global quota stands), is removed when the foreground job ends, and survives if the shell dies (the next session starts a fresh `memfsd`, so nothing outlives a session); a trusted program with the root can see other jobs' directories
- (5) the shell opens `/dev` and `/tmp` for every stage, including pipeline stages that start and end at once (a `mkdir` and a removal each)
- (6) `devd` serves one root directory connection per program (a clone), with the pool limits of `memfsd`.

## Why it was acceptable

The layout and the confined default work and are tested on QEMU.

## Proper fix, and when

- (1) with UV5
- (3) with the terminal work (UV4)
- (4) when per-account byte quotas exist in `memfsd`.
