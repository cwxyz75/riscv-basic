## Shortcut

**UV3 leftovers**:

- (1) `open(path, O_CREAT, mode)` does not record `mode` (only `mkdir` applies mode and umask; `chmod` does it after the fact, which is what `install -m` does)
- (2) `fchmod` and `fchown` use the descriptor's own connection, so a descriptor opened read-only gets `EACCES` where POSIX allows it
- (3) no `utimes`, `futimens`, `lutimes`: times are set by the server
- (4) `st_ino` is a hash of the path (two names for one node differ, a rename changes it) and `st_dev` is the mount's handle number, both only good for the loop detection `find` and `tar` do
- (5) uid and gid are 32-bit in `STAT`
- (6) `access` does not check read and write bits (the handles decide)
- (7) the executable default for the boot image is `bin/` only, and a doofs file is executable only after a `chmod`
- (8) `lchown`, `fchmodat`, `fstatat` and `utimensat` are not provided
- (9) `ls -l` shows no owner, group or time (the image has no times and the owner is the session's).

## Why it was acceptable

Enough for `ls -l`, `install` and `tar`-style programs to work against advisory data.

## Proper fix, and when

Add the `*at` family and `futimens` with the first port that needs them (UV8 BusyBox).
