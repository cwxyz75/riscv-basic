**How.** `cargo-mutants` (a tool installed in the workflow, not a dependency of any crate) over `kcore` and `klock` with the host tests as the oracle, excluding test modules and the frozen reference copies (`sched_smp_v0.rs`). Target `os-mutants`, overnight, sharded by file to fit the budget. Output: the list of surviving mutants as an artifact and in the job summary. First run: every survivor is either killed by a new test or listed in `kcore/mutants-accepted.txt` with a reason (equivalent mutant; diagnostic text). After that the job fails on a survivor not in the list.

**Acceptance, written first.** A deliberately weakened test (one assertion removed) produces a new survivor and a red run.

**Review.** Default. Closes T22 for the kernel crates.
