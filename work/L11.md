## L11a built (2026-11-18)

The owner approved the design note's recommendations (Q-L11 closed). L11a is done: `Sched2`'s shared state is in atomics (`pending`, `online`, `pokes`), each thread's home is an atomic in a thread table (`Home`, the spec's `TT`), and placement and push read published per-hart hints (`cur_eff`, `queued_len`, a `would_run` mask) instead of other harts' queues; own-hart and queued-thread reads are unchanged. The kernel is untouched. Checked by `kcore/tests/sched_smp_l11a.rs`, which drives the new scheduler and a frozen copy of the old one (`sched_smp_v0`, delete with L11b) call for call and compares everything observable (two hand mutations caught: hints not marked stale, a pull not updating the home), by every existing model, `make os-test` (loom and shuttle) and the QEMU suite at `-smp 2` and `-smp 4`.
