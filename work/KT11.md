**How.** `cargo llvm-cov` (tool in the workflow) over `kcore`, `klock`, `abi` and the host build of the syscall layer; line and branch coverage per file in the job summary, the HTML report as an artifact. Not a gate. `TESTING.md` records the first numbers. Files below 80% line coverage get one tidy item naming the uncovered functions.

**Acceptance.** The report exists for a nightly run and names `user`-layer files once TS3 has moved them.

**Review.** Default.
