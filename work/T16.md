## Shortcut

**memfs keeps file data in the server's heap**, programs are copied through memory objects only for `/bin` (S4 spec section 7).

## Why it was acceptable

Simple, host-testable.

## Proper fix, and when

Back files with VMOs (`GetVmo` for everything), shared page cache, `mmap` (S11).
